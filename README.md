# Introduction
Port (via Claude Code) of a RealityKit program I wrote to the Godot game engine. Subsequent additions and improvements were also done via Claude Code.

BoardTestG is a match 3 game in three dimensions. This gives the player more ways to play the game as well as be more visually appealing. Godot gives many graphical abilities that RealityKit does not have, such as built-in physics and better lighting options.

# Modes of Play
## 2D
This is similar to a normal match 3 game, only with some 3D elements. This mode includes blockers that cannot be moved, and the usual game play (including hints for the user).

# Current Status
## Debug
BoardTestG is in development and has a great number of debug features. If commercialized, these features would be removed.
## Levels
BoardTestG effectively has only one level at this time. The size of the board can be controlled by the user and blockers can be added randomly. To be viable, a set of pre-canned levels needs to be added. Additionally, special pieces need to be implemented.
